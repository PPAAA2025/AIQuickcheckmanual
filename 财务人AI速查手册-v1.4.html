使用说明

三条核心规则，先看一眼能少走很多弯路。

怎么用这套手册

  • 每个功能卡里都有一条 提问模板，点「复制提问」按钮即可复制。
  • 模板里的 XX、金额、公司名 是占位符，替换成你的真实数据再发。
  • 涉及数字/表格的，建议 把 Excel、PDF、图片直接拖进对话框，比纯文字描述更准。

数据源与连接器状态

  • 行情、研报、宏观、企业尽调等 实时数据，需要对应的数据连接器处于「已连接/已信任」状态才能查。
  • 连接器未连接时，我会改用 公开网络数据 或 你上传的本地文件 完成任务。
  • 记账、开票、报税类请优先使用对应的财务税务平台连接器，数据更合规。

提问的通用技巧

  • 一次说清 对象 + 数据 + 想要的结果，例如「根据这份表帮我算 X，输出成表格」。
  • 要结果前先给 背景和口径（如「按含税金额」「毛利率=毛利/收入」），避免口径打架。
  • 复杂任务拆成 多步：先算数 → 再分析 → 最后出报告/PPT。

我能直接做的 vs 需连数据源的

  • 可直接做：Excel 处理、报表编制、比率计算、预算模型、报告/PPT、PDF 解析、估值建模。
  • 需连数据源：实时行情、研报、龙虎榜、宏观数据、企业尽调、开票报税。
  • 不确定的，直接把需求丢给我，我会告诉你缺什么、怎么补。
模块 1

日常账务与发票

发票提取与汇总、票据入账、对账结账，以及固定资产折旧、存货成本、期末计提、报销审核等日常账务。

无需连接器，上传发票 PDF/图片即可自动提取、汇总；票据识别可配合扫描识别工具辅助。

发票信息提取

上传发票 PDF/图片，自动提取核心字段并做勾稽校验。

我上传了发票 PDF/图片，帮我自动提取核心信息： 发票号码、开票日期、购买方名称+税号、销售方名称+税号、 项目名称、金额、税率、税额、价税合计 输出成结构化表格，并校验「金额 × 税率 = 税额」是否一致
需准备：发票 PDF / 图片（或截图） 产出：结构化字段表 + 勾稽校验结果
注意：支持一次传多张批量提取；扫描件/模糊图片识别精度会略降，关键数字建议复核。

收集汇总

把多张发票信息收集起来，汇总成台账和统计表。

帮我把这些发票汇总成台账： 1. 上传多张发票 PDF/图片（可分批追加） 2. 逐张提取核心字段，按发票号码自动去重 3. 汇总成一张 Excel 台账（号码、日期、购销方、金额、税额、价税合计） 4. 输出汇总统计（总金额、总税额，按供应商/月份分类）
需准备：多张发票文件（PDF/图片） 产出：发票台账 Excel + 汇总统计表
注意：分批上传时会持续追加到同一台账；重复发票按发票号码自动去重并提示。

银行流水 / 回单 / 合同 PDF 识别入账

从流水、回单、合同里提取关键字段，自动生成记账凭证。

我上传了银行回单/流水/合同 PDF，帮我： 1. 提取关键字段（金额、日期、对方户名、账号、摘要） 2. 判断借贷方向，生成记账凭证 3. 汇总成一张入账明细表
需准备：流水/回单/合同文件（PDF、图片、Excel） 产出：字段提取表 + 记账凭证 + 入账明细
注意：涉及资金收付的凭证建议人工复核后再过账，识别结果可能有少量误差。

月结年结辅助、往来对账、调节表

账面与银行/往来方对账，找差异并出余额调节表。

帮我对账： 1. 上传我方账面明细和银行对账单（或往来方明细） 2. 自动匹配相同记录，标出差异项 3. 生成银行余额调节表 / 往来对账差异表
需准备：双方明细（两份 Excel/PDF） 产出：匹配结果 + 差异清单 + 调节表
注意：对账口径（按金额、日期、摘要）要提前说清，否则匹配结果会不准。

固定资产折旧计算

录入固定资产信息，自动计算月折旧额并生成折旧明细表。

帮我计算固定资产折旧： 1. 上传固定资产清单（资产名称、原值、使用年限、残值率、启用日期） 2. 用平均年限法计算月折旧额、累计折旧、账面净值 3. 生成折旧明细表
需准备：固定资产清单（原值、年限、残值率、启用日期） 产出：折旧明细表 + 月度折旧额
注意：折旧方法（年限平均/双倍余额/年数总和）和残值率要先说清。

存货成本核算

按指定方法核算存货的发出成本和期末结存。

帮我核算存货成本： 1. 上传存货进销存明细（入库数量/单价、出库数量） 2. 用（先进先出/加权平均）法计算发出成本和期末结存 3. 生成存货成本核算表
需准备：进销存明细（数量、单价） 产出：发出成本 + 期末结存 + 成本核算表
注意：成本核算方法（先进先出/加权平均）要与会计政策保持一致。

期末计提与摊销

月末计提预提费用、摊销待摊费用、坏账准备等。

帮我做期末计提与摊销： 1. 列出需要计提/摊销的项目（如房租、保险、利息、坏账准备） 2. 计算各项目本月应计提/摊销金额 3. 生成计提摊销分录
需准备：待计提/摊销项目及金额、期间 产出：计提摊销明细 + 记账分录
注意：计提摊销的期间和基数要准确，否则影响当期损益。

报销合规审核

检查报销单的发票真伪、抬头税号、金额及标准合规性。

帮我审核这张报销单： 1. 上传报销单和发票（图片/PDF） 2. 检查发票真伪、抬头税号、金额是否一致 3. 核对是否符合公司报销标准，标出问题项
需准备：报销单 + 发票 产出：审核结论 + 问题清单
注意：报销标准需提供公司制度，我才能核对是否超标。

差旅 / 招待费标准核对

按公司制度核对差旅费、业务招待费是否超标。

帮我核对这笔差旅/招待费： 1. 提供费用明细（交通、住宿、餐饮、招待） 2. 提供公司报销标准（如住宿限额、餐标、招待比例） 3. 逐项核对是否超标，标出超标项
需准备：费用明细 + 公司报销标准 产出：核对结果 + 超标项清单
注意：业务招待费还有税前扣除比例限制（营业收入的 5‰），可一并提示。
模块 2

税务

所需数据源：报税平台、法规检索工具（需连接对应连接器）。测算与筹划类可直接用我上传的数据完成。

增值税 / 企业所得税 / 个税申报辅助

根据明细数据测算应纳税额，整理申报底稿。

帮我测算本期税额并整理申报数据： 1. 上传销项/进项明细（或收入成本利润数据） 2. 测算应纳增值税（销项-进项）和企业所得税 3. 输出申报数据底稿 + 需要核对的风险点
需准备：销项/进项明细、收入成本费用表 产出：税额测算表 + 申报底稿 + 风险提示
注意：正式申报需在电子税务局等官方平台提交，我负责算数和整理，不代你完成官方申报动作。

税收优惠匹配与税务筹划

按企业特征梳理能享受的优惠，给出合规筹划思路。

帮我做税收优惠梳理和筹划： 我公司属于 XX 行业，注册地 XX，员工数 XX， 年收入 XX 万，是否高新技术/科技型：是/否 帮我列出可享受的优惠（小微、高新、研发加计扣除等），并给合规筹划建议
需准备：行业、规模、地区、资质、收入利润 产出：可享受优惠清单 + 筹划建议 + 注意事项
注意：筹划建议仅供参考，落地前请结合当地政策并由专业税务人员复核。

发票合规与虚开风险排查

检查交易与发票是否三流一致，识别虚开、异常进项等风险。

帮我做发票合规排查： 1. 上传发票清单（或交易特征描述） 2. 检查三流一致（合同、资金、发票）、进项异常、大额顶格、连号开票等 3. 输出风险点清单 + 整改建议
需准备：发票清单/交易流水/合同信息 产出：风险点清单 + 整改建议
注意：这属于自查辅助，重大风险请以税务稽查口径为准。

工资与个税计算

按工资表计算应发、社保公积金、个税和实发金额。

帮我计算工资和个税： 1. 上传工资表（基本工资、补贴、奖金、社保公积金基数） 2. 计算应发工资、个人社保公积金、个税（累计预扣法）、实发 3. 生成工资明细表和个税计算表
需准备：工资表 + 社保公积金基数/比例 + 专项附加扣除 产出：工资明细 + 个税计算表
注意：个税按累计预扣法，专项附加扣除项目（子女教育、房贷等）要提供完整。

财务报表与分析

无需数据源，上传科目余额表、试算平衡表或财务数据即可直接完成。

帮我编报表： 1. 上传科目余额表 / 试算平衡表 2. 生成资产负债表、利润表 3. 尽可能编制现金流量表（间接法/直接法） 4. 校验勾稽关系，标出不平的地方
需准备：科目余额表 / 试算平衡表（Excel） 产出：三张报表 + 勾稽校验说明
注意：现金流量表若明细不足，我会用间接法估算并标注假设。

财务比率计算与解读

算核心财务比率并给出通俗解读和行业对标。

帮我算财务比率并解读： 1. 上传财报数据（或给关键科目数） 2. 计算 ROE、ROA、毛利率、净利率、周转率、资产负债率、流动比率等 3. 逐项解读 + 和行业水平对标 + 指出异常点

注意：说清口径（如毛利率=毛利/收入），否则不同口径结果会打架。

经营分析报告 / PPT 生成

把经营数据变成有结论、有原因、有建议的报告或 PPT。

帮我写经营分析报告并生成 PPT： 1. 上传本月/本年经营数据（收入、成本、费用、利润） 2. 分析变动原因（同比/环比/预算差异） 3. 输出 Word 报告 + 一份汇报 PPT
需准备：经营数据（Excel/口径说明） 产出：分析报告 + 汇报 PPT
注意：告诉我汇报对象（管理层/董事会），我会调整详略和措辞。

合并报表抵销

帮我做合并报表抵销： 1. 提供母子公司报表 + 内部往来/交易明细 2. 抵销内部往来、内部交易、未实现利润 3. 生成抵销分录和合并工作底稿

报表附注编制

帮我做敏感性分析： 1. 提供基础财务数据（收入、成本、利润） 2. 假设价格/成本/销量分别变动 ±5%、±10% 3. 测算各因素对利润的影响程度，输出敏感性分析表
需准备：基础财务数据 + 变动幅度 产出：敏感性分析表 + 影响排序
注意：可指定单因素或多因素联动分析。

贷款利息与还款计划

按贷款要素计算利息并生成还款计划。

成本归集与分摊、采购价格与降本、成本差异、库存与损耗管理。

无需连接器，上传采购明细、成本数据、收发存数据即可处理。

采购价格与降本分析

分析采购价差异、供应商比价、降本项目。

帮我做采购价格分析： 1. 上传采购明细（物料、供应商、价格、数量） 2. 识别同物料不同供应商的价格差异、异常价格、量折扣是否兑现 3. 生成降本项目清单并跟踪兑现情况
需准备：采购明细 产出：价格差异 + 降本清单
注意：比价要区分物料规格和采购条件，否则可比性失真。

成本差异分析

拆解标准成本与实际成本差异（料工费）。

帮我做成本差异分析： 1. 提供标准成本和实际成本数据 2. 拆解材料、人工、制造费用差异 3. 计算单位成本、订单/项目真实毛利，识别低毛利负毛利
需准备：标准/实际成本数据 产出：差异拆解 + 单位成本 + 毛利分析
注意：料工费差异要分别归因（价格差/用量差），才可执行。

库存与损耗管理

识别呆滞库存、损耗率、库存资金占用。

帮我做库存分析： 1. 上传收发存数据 2. 识别呆滞/积压库存、异常报废和盘亏 3. 预测库存资金占用，模拟采购批量和安全库存
需准备：收发存数据 产出：呆滞库存清单 + 资金占用预测
注意：呆滞判定需定义周期（如 90 天无出库），我会按你的口径。
模块 14

项目、工程与合同财务

项目预算与完工跟踪、合同财务信息提取与风险。

无需连接器，上传项目合同、成本明细即可处理。

项目预算与完工跟踪

建项目预算，跟踪成本、完工百分比、超预算。

帮我做项目财务跟踪： 1. 上传项目合同和成本明细 2. 建立项目预算，追踪成本发生和完工百分比 3. 识别超预算，预测最终成本，计算项目毛利和现金回收
需准备：项目合同 + 成本明细 产出：项目预算 + 完工跟踪 + 毛利
注意：完工百分比按投入法或产出法，需明确口径。

合同财务信息提取

从合同提取金额、里程碑、付款条件、风险条款。

帮我提取合同财务信息： 1. 上传项目合同 2. 提取金额、里程碑、付款条件、违约金、折扣 3. 识别租赁、金融工具、履约义务等会计事项，生成合同风险摘要
需准备：合同文件 产出：合同财务信息表 + 风险摘要
注意：租赁、金融工具等事项判断需专业复核，我提供初判。
模块 15

并购、投融资与尽调

财务尽调数据整理、交易建模与回报测算、投委会材料。

无需连接器，上传 BP、审计报告、合同、流水、交易假设即可处理。

财务尽调数据整理

批量读取 BP、审计报告、合同、流水，交叉核对。

帮我做财务尽调数据整理： 1. 上传 BP、审计报告、合同、银行流水 2. 提取收入、客户、供应商、负债、现金数据，建立证据索引 3. 交叉核对，识别收入确认异常、关联交易、未披露债务
需准备：尽调资料（BP/审计报告/合同/流水） 产出：数据提取 + 交叉核对 + 问题清单
注意：交叉核对是关键，我会标出不同文件间数字不一致处。

交易建模与回报测算

模拟估值、杠杆、退出回报，计算 IRR/MOIC。

帮我做交易建模： 1. 提供交易假设（估值、杠杆、退出倍数、期限） 2. 计算 EBITDA、净债务、营运资金 3. 模拟估值和回报，分析条款对 IRR、MOIC、现金流的影响
需准备：财务数据 + 交易假设 产出：估值模型 + IRR/MOIC 测算
注意：IRR/MOIC 高度依赖假设，我会做敏感性分析。

投委会材料生成

生成投委会材料初稿，检查估值模型逻辑。

帮我生成投委会材料： 1. 提供尽调结论和交易方案 2. 生成投委会材料初稿 3. 检查估值模型的公式和逻辑，更新假设
需准备：尽调结论 + 交易方案 产出：投委会材料初稿
注意：估值模型公式我会逐一校验，标出逻辑错误。

需准备：数据处理需求 产出：脚本 + 指标口径字典

财务知识库与问答

建立财务知识库，回答制度流程问题。

帮我建财务知识库： 1. 上传制度、流程、历史问答 2. 整理成标准作业指引和知识库 3. 新员工可通过问答查询制度、流程和案例
需准备：制度/流程/历史问答 产出：知识库 + 标准作业指引
注意：知识库内容需定期更新，保持和现行制度一致。
